(If you'd only like to toggle between 2 levels, use -1 as the 3rd level.)




Per-site base zoom levels (optional):

One site per line, as domain, base_zoom_level. A domain also covers its subdomains.

So whether to include www. matters: nytimes.com covers the whole site, including www.nytimes.com and cooking.nytimes.com, while www.nytimes.com only covers www.nytimes.com. To cover a whole site, leave out www..

On a listed site, the zoom levels above become multipliers of its base zoom level. For example, with github.com, 90, a zoom level of 110 shows GitHub at 99% (90% × 110%). Sites that are not listed have a base zoom level of 100.

When you save, the browser asks for permission to access the listed sites. The extension only uses it to tell which tabs are on these sites, so that it can apply their base zoom levels.
